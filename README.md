# Minh Tai Resume

Static resume/CV page deployed with GitHub Pages.

## Local preview

Open the file directly or run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## GitHub Pages

This repo is set up to work with GitHub Pages using the static site workflow in `.github/workflows/pages.yml`.

Suggested repo name:

```text
minh-tai-cv
```
